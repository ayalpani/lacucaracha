# Umgebungen

| Umgebung | Wo | Deploy |
|---|---|---|
| Staging | GitHub Pages des Repos (`https://<owner>.github.io/lacucaracha/`) | Automatisch bei jedem Push auf `main` (`.github/workflows/staging.yml`) |
| Production | Noch keine. Später: Google Play Store (native App) | Nur nach ausdrücklichem OK |

GitHub Pages muss einmalig unter *Settings → Pages → Source: GitHub Actions* aktiviert sein.
