# Kakerlaken-Modell

Lege hier `roach.glb` ab, dann nutzt die App dieses 3D-Modell statt der eingebauten Kakerlake.

- Format: GLB (glTF binär), statisches Mesh reicht. Rig/Animationen werden ignoriert, die App bewegt Beine und Fühler selbst.
- Größe/Ausrichtung egal: die App skaliert auf ~3,6 cm Körperlänge, stellt die Füße auf den Boden und dreht die lange Achse nach vorn (Fühler = vorn).
- Bitte low-poly: höchstens ~5.000 Dreiecke, Textur 1024 px. Es laufen bis zu 220 Tiere gleichzeitig.
